# YourSpace - JavaScript2-Course Assignment

This is a simple social media application that I built for the JavaScript 2 course at Noroff.
Users can register, log in, browse posts and manage their own content.

## Links

- Live website: https://denise-cramer.github.io/JavaScript2-CA/
- GitHub Repository: https://github.com/Denise-Cramer/JavaScript2-CA

## Features

- Register and login with a Noroff student e-mail
- Browse and view posts
- Create, edit and delete ones own posts
- Search posts by title or text
- View ones own profile and other users profiles and posts
- Follow and unfollow other users
- Logout

## Built with

- HTML
- CSS
- JavaScript ES6 modules
- Noroff API v2
- GitHub Pages

## Run locally

1. Clone the repository:

    git clone https://github.com/Denise-Cramer/JavaScript2-CA.git

2. Open the project folder in VS Code.
3. Use the Live Server extension to open index.html.
4. Register with a @stud.noroff.no email address, or log in if you already hav an existing one.

## API and authentication

The application uses the Noroff Social API v2.
